# Model Router

Это правило выбора исполнителя, не автоматический переключатель.
Явный выбор пользователя важнее значения по умолчанию.
Наличие этого файла не разрешает само по себе запуск дополнительных агентов.
Исключение, разрешённое владельцем: локальный Qwen по [qwen.md](qwen.md).

## Qwen — локальный сбор фактов
Используй scripts/qwen-worker.ps1 только для узкого read-only исследования,
если короткий отчёт заменит широкое чтение. Если достаточно одного rg, используй rg.
Qwen не принимает архитектурные/визуальные решения, не правит код и не запускает
других исполнителей. При ошибке или таймауте продолжай основной моделью.

## Default: GPT-6 Sol
Обычная разработка, локальные исправления, реализация известного подхода.
Профиль: [sol](sol.md).

## Luna
Только если одновременно: задача детерминирована, повторяема, узкая,
проверяется однозначно и не требует дизайнерского решения.
Примеры: применение утверждённого паттерна, проверка ссылок, точная замена текста.
Переименование маршрута или содержательное изменение metadata не становится
механическим только из-за короткого названия задачи.
Профиль: [luna](luna.md).

## Astra
Когда архитектура неясна, есть существенные tradeoffs, конфликт UX/дизайна/техники,
затрагиваются несколько крупных систем, высока цена отката, запрошено целостное
ревью этапа либо Sol дважды не решил одну проблему.
Две неудачи — две обоснованные попытки с проверкой результата, не две ошибки shell.
Профиль: [astra](astra.md).

## Передача и возврат
Перед передачей указать цель, разрешённые файлы, неизменяемые условия,
критерий готовности, проверки и сведения о грязном дереве.
При неопределённости исполнитель прекращает механические изменения и возвращает
конкретный вопрос/варианты основной модели.
После архитектурного решения реализацию можно вернуть Sol с записанным решением.

Выбирать модель только доступным механизмом среды и в рамках разрешённой работы.
Если его нет, сообщить об ограничении; не заявлять о переключении.
Не создавать новые чаты или параллельных исполнителей без авторизации.
