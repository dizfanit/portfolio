# 003 — Система анимации

Дата: 2026-09-27. Статус: существующее решение, зафиксировано по коду.

Motion реализован несколькими средствами: framer-motion для React-переходов,
CSS для визуальных состояний, Canvas для LiquidReveal и requestAnimationFrame
для процедурных эффектов/скролла. Общего motion-controller нет.

Не вводим вторую animation-библиотеку и не переписываем всё на один механизм
без измеримой причины. Цена существующей схемы — необходимость согласовывать
cleanup, reduced motion и одновременную работу эффектов.

Альтернатива — единая абстракция управления движением; пока не принята.
Пересмотр нужен при повторяющихся конфликтах или измеренной нагрузке.
Защищённые поведения описаны в [motion](../design/motion.md).
