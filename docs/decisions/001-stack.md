# 001 — Стек

Дата: 2026-09-27. Статус: существующее решение, зафиксировано по коду.
Исторические мотивы выбора не документированы.

Сайт использует Next.js App Router, React, TypeScript strict, Tailwind CSS,
framer-motion и локальные данные. Сохраняем основу при текущих задачах.
Альтернативы вроде CMS или отдельного backend сейчас не внедряем:
в имеющемся сценарии нет соответствующей потребности.

Последствие: контент меняется через репозиторий; статические маршруты кейсов
зависят от массива данных. Пересмотр нужен при регулярном редактировании
контента без разработчика или появлении серверных функций.
