# 002 — Переходы между секциями

Дата: 2026-09-27. Статус: существующая реализация с известными ограничениями.

Главная построена как последовательность экранов. Используются CSS scroll snap
и SmoothSectionScroll, перехватывающий ввод. Отдельные route-анимации между
главной и кейсами в рассмотренном коде не реализованы.

Фиксируем фактическую схему; не объявляем глобальный перехват ввода окончательно
одобренным UX. Он конфликтует с интерактивными элементами и высокими секциями.
Альтернативы для будущей задачи: нативный скролл со snap либо ограниченный контроллер
с исключениями. Выбор требует проверки конкретных сценариев.

При пересмотре сохранить последовательность разделов и чувство переходов,
проверить клавиатуру, вложенную прокрутку, preview и достижимость контента.
