# Архитектурные решения

ADR — короткая запись существенного решения: контекст, выбор, последствия
и когда его стоит пересмотреть. Не заводить ADR на каждую правку.

- [001 — Стек](001-stack.md)
- [002 — Переходы между секциями](002-page-transitions.md)
- [003 — Система анимации](003-animation-system.md)
- [004 — Документация и рабочий процесс](004-project-harness.md)

001–003 фиксируют существующую реализацию на дату обзора, не выдумывая историю
её выбора. Известные недостатки не считаются одобренными решениями.
Новый файл: следующий номер, дата, статус (предложено/принято/заменено),
контекст, решение, альтернативы, последствия, критерий пересмотра.
