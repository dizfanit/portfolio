## Surprises & Discoveries


useBoardPan ограничивает смещение интервалами от отрицательной разницы размеров холста и viewport до нуля. Если размеры совпадают, весь интервал равен нулю: движение невозможно. У Work вертикальное движение на компактном экране дополнительно отключено по умолчанию.

CaseMediaPreview уже поддерживает локальную прокрутку для media.preview = scroll и сохраняет непрерывный возврат прокрученной страницы. Причина малого горизонтального окна — aspect-ratio: 16 / 9 в .pageBounds и высота от низа действий. Эту существующую механику нужно сохранить, меняя только геометрию окна.

Текущий курсор кейса является отдельной плавающей board-dismiss кнопкой внутри native dialog. Dialog — верхний слой браузера, поэтому глобальный декоративный курсор не следует переносить в него. Work использует существующий SVG public/cursors/close.svg.

Первоначальное увеличение до 80vw перекрывало 50px кнопки справа. Свежий агент измерил реальную ширину Close и добавил симметричный запас. Итоговый зазор равен 24px, верх совпадает точно.

Сервер на 3000 продолжал отдавать старые CSS. Его Fast Refresh также зарегистрировал известную ошибку изменения длины dependencies эффекта. Проверку перенесли на свежую production сборку 127.0.0.1:3001: computed styles подтвердили четыре края по 360px и отсутствие пятна; ошибок её URL в журнале браузера нет. Старый сервер не останавливался.

Qwen завершился с exit code 0, но вернул команду PowerShell вместо отчёта. Вывод не использовался как доказательство; механизм курсора перепроверен по исходнику и computed styles без повторного запуска.
