# Планы

[active](active.md) содержит только выполняемую работу; [completed](completed.md) —
ссылки на завершённую. [backlog](backlog.md) — кандидаты, не разрешение на реализацию.

Для сложной функции или значительного рефакторинга:
создать YYYY-MM-DD-short-name.md по [PLANS.md](../../PLANS.md), записать результат,
границы и критерии, добавить ссылку в active. Поддерживать Progress, Discoveries,
Decision Log и Outcomes. При завершении записать реальные проверки, убрать из active,
добавить в completed; сам файл не переносить, чтобы ссылки оставались стабильными.

Для небольшой правки отдельный план не обязателен.
Если прервались, записать сделанное, оставшееся, блокер и точный следующий шаг.
Не помечать работу завершённой только из-за окончания сеанса.
