## Purpose / Big Picture

В Work и подробных кейсах края доски должны плавно темнеть к периметру, включая низ. На desktop сетка кейса заполняет экран за неподвижным интерфейсом. Карточки Work имеют красную рамку, которая становится белой при наведении. Пользователь плавно перемещает доску; изображения остаются прикреплёнными к ней. При увеличении и возврате рамка движется вместе с изображением, без оставшейся рамки миниатюры.

## Surprises & Discoveries

useBoardPan обновляет React state на каждом pointermove. Дочерние motion-изображения с layoutId (идентификатор пары миниатюра/увеличенное изображение) поэтому повторно измеряют положение при панорамировании. Рамка CaseStudyBoard находится на button, тогда как увеличивается вложенный motion.div. В Work горизонтальный градиент есть, вертикального на desktop нет. Начало board кейса ограничено case-content-top.

Браузер выявил, что начальный jump центрированного холста может выполняться до подписки useMotionTemplate: холст начинался в (-360, -360), сетка в (0, 0). Теперь updateBounds явно синхронизирует backgroundPosition; после перезагрузки оба положения равны (-360, -360). Во время drag координаты материала относительно холста стабильны в пределах 0.0002 px, собственный transform изображения — none.

Изменение числа зависимостей effect через Fast Refresh дало одно служебное предупреждение React в текущей dev-сессии. После полной перезагрузки и проверки цепочки новых ошибок нет. Попытка запустить dev показала EADDRINUSE; проверка продолжена на уже работающем сервере, чужие процессы не остановлены.

## Decision Log

Решение: использовать Motion values — значения положения, которые библиотека обновляет без React render — для общего движения холста и сетки. Пружина сглаживает только их общее положение; собственную анимацию перемещения изображений не добавлять. При открытии превью останавливать движение. При reduced motion перемещать сразу. Автор: Codex, 2026-10-05.

Решение: рамка принадлежит анимируемому визуалу. Исходный визуал скрывается без изменения размеров до завершения возврата; тогда не остаётся дублирующей рамки. Мобильный поток панели перед доской сохраняется. Автор: Codex, 2026-10-05.

## Validation and Acceptance

На четырёх краях виден плавный переход от тёмного к прозрачному в центре. Сетка кейса проходит за шапкой до верхней границы экрана. При drag карточка сохраняет своё положение относительно холста и не догоняет указатель отдельно. Плавное движение имеет короткое затухание без отскока за границы. После drag не открывается просмотр. В превью и на обратном переходе движется одна рамка вместе с изображением. Закрытие возвращает исходное положение и фокус. При reduced motion отсутствует пружинное движение и переход увеличения.

## Idempotence and Recovery

Существующее дерево содержит изменения пользователя. Не сбрасывать файлы, не делать коммиты и не удалять ассеты или состояние. Исправления ограничены названными владельцами; повторная сборка безопасна. При ошибке сохранять источник и исправлять только изменения задачи. Удалять можно только временные файлы этой проверки.
