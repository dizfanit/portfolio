## Surprises & Discoveries

Только project-07 имеет CaseStudyBoard; остальные маршруты показывают длинную страницу с заглушками. У Abby в data/caseStudies.ts ровно одно предоставленное изображение. Повторный клиентский возврат через Next Link href=/#work воспроизвёл адрес /#work#work. Прямое исходное открытие мышью на QHD скачка к Hero не воспроизвело; фокус частично скрытых карточек и активная секционная анимация оставались путями нежелательной прокрутки.

Dev-сервер не подхватил дописанный через Add-Content общий CSS до следующего точечного изменения файла. Проверка computedStyle обнаружила отсутствие border/uppercase; после обновления стили загрузились. Временный тестовый маршрут сначала вернул 500 из-за запрещённых query strings у локального next/image; fixture исправлен на повторное использование исходного пути без изменения конфигурации и затем удалён.

## Decision Log

Решение от 2026-10-05: использовать единый CaseStudyBoard во всех существующих slug. Для незаполненных кейсов сохранить известные описания и явно обозначить отсутствие материалов внутри информационной панели; на доске не создавать фиктивные изображения.

Решение от 2026-10-05: общую механику pointer drag (перемещение мышью или касанием с порогом, ограничениями и подавлением клика после перетаскивания) выделить из WorkBoard в hooks/useBoardPan.ts. Размеры ограничений вычислять по реальному холсту, а не задавать постоянные числа.

Решение от 2026-10-05: вернуть пользователя через /?section=work с scroll:false, затем в WorkBoard установить /#work и мгновенно восстановить координату секции. Обычный href остаётся /#work для новой вкладки; это устраняет воспроизведённое удвоение hash без вмешательства в Hero и прелоадер.

Решение от 2026-10-05: холст кейса имеет запас пространства и начальное центрирование, чтобы даже единственное изображение можно было перемещать в обе стороны. Панель никогда не движется вместе с холстом. Размеры текста берутся из существующих токенов, контент аккордеонов не сокращается.
