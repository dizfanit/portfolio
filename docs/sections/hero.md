# Hero

Владелец: components/Hero.tsx; навигация — components/Header.tsx;
стили — .hero-* и общие токены app/globals.css.

Назначение: показать специализацию и характер дизайнера, дать путь к обращению.
Текущее поведение: фоновое muted loop-видео с постером, русский h1,
описание, CTA «Связаться» → #contact. Header ведёт к #work, #about, #contact.

Сохранять композицию первого экрана, responsive-позицию медиа, фокусные углы,
CTA и handoff прелоадера. Путь видео также используется в Preloader.
Изменение одного требует проверки второго.

При правках проверить QHD, читаемость поверх видео, постер, CTA, якоря
и взаимодействие с фиксированным Header.
Правила: [visual](../design/visual-system.md), [motion](../design/motion.md).
